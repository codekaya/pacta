# Brand — Pacta

_Status: active_

Editorial receipt. The product is a deposit notice from a clinic, not a SaaS landing page.

## Direction

Private-clinic letterhead × bank guarantee. Paper, ink, one oxblood accent. Asymmetric, left-aligned, almost no chrome.

## Palette

| Token | Value | Role |
|---|---|---|
| `paper` | `#F3EEE4` | Page |
| `desk` | `#E4D9C8` | Rare outer edge |
| `ink` | `#1A1612` | Text, primary button |
| `muted` | `#534C43` | Secondary text (AA on paper) |
| `rule` | `#D4CBBC` | Hairlines |
| `oxblood` | `#6B2D28` | Active policy row, links, focus |
| `forest` | `#2C4A38` | Held / released status |

No gradients. No cool gray. No emerald-500.

## Type

- Display: Newsreader (serif)
- UI: Public Sans
- Figures / addresses: IBM Plex Mono

## Voice

English. Dry, specific, contractual. Dates and amounts, not slogans.

## Radius

None on the document. Buttons are square.
